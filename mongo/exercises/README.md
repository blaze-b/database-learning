# exercises/

Practice problems with worked mongosh solutions against the sanitised `learning_mongo.profiles` collection.

## Start here

1. From `mongo/`, run `npm run seed`.
2. Open [`mongodb-exercises.md`](mongodb-exercises.md).
3. Try each exercise in mongosh, then compare with the solution.

Exercises cover `countDocuments`, projection, `$regex`, `$set`, `$gte` on embedded fields, and `$expr` + `$size` with sort.
